# Worker Async Idempotency

## 适用场景

生成或修改定时任务、MQ consumer/listener、事件 handler/subscriber、异步任务、锁、幂等、ack/nack、重试或补偿任务时读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Job、Consumer、Listener、EventHandler、Async Task、锁、幂等键 |
| 动作 | 定时触发、消息消费、事件订阅、异步执行、失败重试、补偿 |
| 风险 | 重复消费、重复副作用、锁 key 不稳、ack 时机错误、上下文缺失 |
| 可跳过 | 同步链路且无并发、重试或异步触发 |

## 决策表

| 场景 | 入口职责 | 必须下沉 |
| --- | --- | --- |
| 定时任务 | 触发、分页范围、锁、结果摘要 | 复杂业务规则到 Service |
| MQ 消费 | 解析消息、幂等、ack/nack、重试 | 状态变更和外部编排到 Service |
| 事件处理 | 校验事件、去重、调用 Service | 业务副作用到 Service |
| 异步任务 | 上下文装配、异常兜底、调用 Service | 核心流程到 Service/Facade |

## 门禁

- Worker 入口只做触发、解析、锁、ack/nack、重试策略和调用 service。
- 必须明确幂等键、锁粒度、重试次数、失败记录和告警或可观测方式。
- 异步和线程池执行前设置必要上下文，执行后必须清理。

## 交付要求

| 项 | 必填内容 |
| --- | --- |
| 触发源 | cron/MQ topic/event/async caller |
| 消息或参数 | 字段语义、来源和校验 |
| 幂等键 | 组成、唯一性和重复处理 |
| 锁与重试 | 锁 key、临界区、重试次数和终止条件 |
| ack/nack | 成功、业务失败、系统异常各自处理 |
| 调用 Service | 目标 service 方法和返回语义 |

## 高风险反例

- Consumer 里直接堆完整业务流程。
- 消息处理成功前提前 ack。
- 幂等键使用随机值，无法识别重复消息。
- 异步任务不清理线程上下文。
