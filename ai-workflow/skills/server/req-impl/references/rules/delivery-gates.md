# Delivery Gates

## 适用场景

`server/req-impl` 交付前必须读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Service/Facade/Worker 业务代码、业务契约、交付说明 |
| 动作 | 完成业务实现、准备交付、说明验证和风险 |
| 风险 | 契约影响不明、数据影响不明、验证不足、剩余风险不明 |
| 可跳过 | 不可跳过 |

## 门禁

| 门禁 | 要求 |
| --- | --- |
| 规则自检 | 已说明命中的规则文件和未命中原因 |
| 契约影响 | 已说明业务契约、入口契约、持久化契约和外部能力影响 |
| 数据影响 | 已说明数据、枚举、配置、兼容 SQL 或不涉及依据 |
| 验证 | 已执行最小验证，或给出未执行原因和可执行命令 |
| 风险 | 已列出剩余风险、兼容影响、发布注意和待确认项 |
| 敏感信息 | 不在日志、注释、测试资产、配置示例或交付说明中复写 token、账号、密码、签名、连接串和密钥 |
| 真实来源 | SDK、Client、Facade、Adapter、YApi、配置项、码值和表结构来自源码、契约或已确认输入 |
| 最小范围 | 只完成当前业务闭环，不顺手扩展抽象、重构无关模块或新增未要求能力 |
| 兼容风险 | 涉及旧接口、旧数据、旧任务、租户隔离或资金资产链路时已说明兼容、回滚和剩余风险 |

## 交付格式

| 项 | 内容 |
| --- | --- |
| 步骤摘要 | Fast Path / Full Path 和关键步骤 |
| 命中规则 | 本次读取的规则文件 |
| 实现文件 | 新增和修改文件 |
| 业务契约 | Service/Facade 方法、字段规则、错误语义 |
| Worker 契约 | 命中异步入口时填写 |
| 数据影响 | 表、字段、枚举、配置和兼容 |
| 验证结果 | 命令、PASS/FAIL/NOT_RUN |
| 剩余风险 | 风险、阻塞、后续动作 |
