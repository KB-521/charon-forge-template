# External Integration

## 适用场景

生成或修改 SDK、Client、Facade、Adapter、三方 HTTP/gRPC 调用、回调、文件、计费、导入或导出业务编排时读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Client、Adapter、外部 DTO、回调处理、计费处理、文件导入导出 |
| 动作 | 调用外部系统、接收回调、生成 URL、扣费、退款、解析文件、导出文件 |
| 风险 | SDK 未确认、超时重试不明、外部模型污染内部、计费回退缺失 |
| 可跳过 | 不涉及外部系统、文件、媒体、计费、导入或导出 |

## 决策表

| 场景 | 默认边界 | 必须说明 |
| --- | --- | --- |
| HTTP/SDK 调用 | Client/Adapter/Facade 或项目等价封装 | 真实接入点、超时、重试、异常映射 |
| 外部回调 | 独立回调模型和签名校验 | 幂等、状态映射、失败处理 |
| 文件/媒体 | 统一文件或媒体适配能力 | 路径、访问 URL、权限和脱敏 |
| 计费/资产 | 业务 service 编排 | 预扣、确认、回退、幂等和审计 |
| 导入导出 | 专项解析/导出组件 | 数据量、权限、行级错误和结果摘要 |

## 门禁

- 外部能力必须确认 SDK、Client、Facade、Adapter、YApi、接口文档或调用样例。
- Controller/Endpoint 不直接调用外部系统。
- 外部请求/响应模型独立建模，不直接作为内部接口契约透出。
- 计费、资产、公开写入口必须明确幂等和补偿。

## 交付要求

| 项 | 必填内容 |
| --- | --- |
| 真实接入点 | SDK/Client/Facade/Adapter/接口文档/源码证据 |
| 调用边界 | 超时、重试、降级、异常映射 |
| 模型转换 | 外部模型与内部模型转换位置 |
| 副作用 | 计费、资产、文件、回调、消息等影响 |
| 风险 | 下游不可用、重复调用、敏感字段、兼容影响 |

## 高风险反例

- Service 中临时 new 第三方客户端。
- 把第三方响应对象直接返回前端。
- 计费成功后业务失败但没有回退或补偿。
