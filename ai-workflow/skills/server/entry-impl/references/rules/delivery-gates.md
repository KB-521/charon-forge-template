# Delivery Gates

## 适用场景

`server/entry-impl` 交付前必须读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Endpoint/Controller、DTO、VO、入口契约、交付说明 |
| 动作 | 新增入口、修改入口、完成入口层实现、准备交付 |
| 风险 | 字段契约漂移、YApi 缺口、验证不足、剩余风险不明 |
| 可跳过 | 不可跳过 |

## 门禁

| 门禁 | 要求 |
| --- | --- |
| API 契约 | path、method、request、response、错误码和兼容影响已确认 |
| Service 能力 | 已确认调用的 service 方法、入参语义和返回语义 |
| 字段对齐 | DTO/VO 与 API 契约逐项对齐 |
| YApi | 已说明是否需要同步；Controller 自动同步缺口已标注 |
| 验证 | 已执行编译/api-mock 或说明未执行原因 |
| 敏感信息 | 不在 DTO/VO、日志、注释、示例或交付说明中复写 token、账号、密码、签名、连接串和密钥 |
| 真实来源 | API 契约、Service 方法、权限、错误码和字段语义来自源码、契约或已确认输入 |
| 最小范围 | 只做协议适配和 service 调用，不顺手实现业务规则、持久化能力或无关重构 |
| 兼容风险 | 涉及旧接口、旧客户端、租户隔离或资金资产链路时已说明兼容、回滚和剩余风险 |

## 交付格式

| 项 | 内容 |
| --- | --- |
| API 契约 | 路由、method、字段级 request/response |
| 修改文件 | Endpoint/Controller、DTO、VO |
| 调用 Service | 方法、转换和错误映射 |
| 安全校验 | 鉴权、权限、审计、敏感字段 |
| YApi | 自动同步/手工同步/需扩展 |
| 验证结果 | 命令、PASS/FAIL/NOT_RUN |
| 剩余风险 | 兼容、文档、联调和待确认项 |
| 命中规则 | 本次读取的规则文件 |
