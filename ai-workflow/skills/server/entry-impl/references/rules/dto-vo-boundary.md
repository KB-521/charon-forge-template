# DTO VO Boundary

## 适用场景

新增或修改 Request DTO、Response VO、Query、分页响应、字段裁剪、模型转换或对外字段展示时读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | DTO、VO、Query、分页对象、字段转换 |
| 动作 | 新增字段、调整字段含义、裁剪字段、转换枚举或展示值 |
| 风险 | 内部字段透出、敏感字段泄露、DTO 复用混乱 |
| 可跳过 | 不新增或修改 DTO/VO |

## 决策表

| 模型 | 只能承载 | 禁止承载 |
| --- | --- | --- |
| Request DTO | 入参字段和结构校验 | 出参字段、持久化控制字段 |
| Query | 查询、分页、排序和过滤 | 写入字段和流程状态 |
| Response VO | 前端可见字段 | 内部控制字段、敏感字段、存储态字段 |
| PO/BO | 内部持久化或业务中间态 | 直接作为对外契约 |

## 门禁

- DTO/VO 字段必须与 API 契约逐项对齐。
- 禁止直接暴露 PO、内部 BO、第三方原始响应或敏感字段。
- 枚举、状态、时间、金额、媒体字段必须按契约转换为展示语义。

## 交付要求

| 项 | 必填内容 |
| --- | --- |
| 字段来源 | API 契约、Service 返回模型或已确认输入 |
| 字段裁剪 | 内部字段、敏感字段、存储态字段处理 |
| 转换逻辑 | 枚举、时间、金额、媒体 URL、状态展示 |
| 兼容影响 | 新增、删除、改含义或改默认值 |

## 高风险反例

- 一个 DTO 同时作为新增、更新、查询和出参。
- VO 原样返回 PO 字段。
- 第三方响应对象直接返回前端。
