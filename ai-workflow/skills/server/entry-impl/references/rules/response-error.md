# Response Error

## 适用场景

新增或修改响应封装、异常映射、错误码、分页结构、空结果语义或响应兼容时读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | ResponseDTO、分页响应、异常处理、错误码映射 |
| 动作 | 新增响应结构、调整错误语义、修改分页或空结果 |
| 风险 | 响应不统一、内部异常泄露、错误码不兼容 |
| 可跳过 | 不涉及响应或错误语义 |

## 决策表

| 场景 | 规则 |
| --- | --- |
| 成功详情 | 使用项目统一响应包装的 VO |
| 列表/分页 | 使用项目统一列表或分页包装 |
| 空结果 | 返回空对象、空集合或统一空分页，不返回不明 null |
| 业务失败 | 通过统一异常和失败响应出口处理 |
| 未知异常 | 不透出异常栈、内部配置或敏感信息 |

## 门禁

- 响应封装必须符合项目既有风格，不新增临时返回结构。
- 错误码、异常映射和响应封装必须与 API 契约一致。
- 对外返回不得泄露内部异常栈、配置、token 或敏感字段。

## 交付要求

| 项 | 必填内容 |
| --- | --- |
| 成功响应 | 包装类型、data 字段和空结果语义 |
| 失败响应 | 错误码、异常来源和映射方式 |
| 分页响应 | 页码、页大小、总数和列表字段 |
| 兼容影响 | 旧客户端是否受影响 |

## 高风险反例

- 返回裸 Map、裸 List 或第三方原始响应。
- catch 后返回成功。
- 对外响应包含异常栈。
