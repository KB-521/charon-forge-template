# Validation Auth Audit

## 适用场景

新增或修改参数校验、鉴权、权限、审计注解、上下文提取或公开入口安全边界时读取。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 校验注解、权限注解、审计注解、上下文参数 |
| 动作 | 新增校验、调整权限、公开入口、提取租户/用户上下文 |
| 风险 | 参数绕过、权限缺失、审计缺证据、租户越权 |
| 可跳过 | 不涉及校验、权限、审计或上下文 |

## 决策表

| 场景 | 规则 |
| --- | --- |
| DTO 校验 | 非空、长度、枚举、格式、集合和嵌套对象按契约设置 |
| 鉴权权限 | 按项目既有注解或拦截方式处理 |
| 审计 | 有业务副作用的公开写接口必须评估 |
| 上下文 | 租户、组织、用户、requestId 来源明确 |
| open 豁免 | 必须有业务依据和安全边界 |

## 门禁

- 参数校验必须放在入口层或复用项目统一校验，不能依赖前端保证。
- 权限口径不明时输出缺口，不猜测注解。
- 审计参数不得包含密码、token、证件号、手机号全量、完整请求体。

## 交付要求

| 项 | 必填内容 |
| --- | --- |
| 校验 | 字段、规则、错误语义 |
| 鉴权权限 | 注解、拦截器或不涉及依据 |
| 审计 | 是否需要、记录字段和脱敏 |
| 上下文 | 租户、用户、组织、requestId 来源 |

## 高风险反例

- 校验注解贴在不生效的位置。
- open 入口没有签名、权限或数据范围依据。
- 写接口未评估审计。
