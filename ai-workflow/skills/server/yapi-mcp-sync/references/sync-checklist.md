# YApi MCP 同步检查清单

## 字段解析规则

- 字段说明优先取字段注释 / Javadoc、`@Schema / @ApiModelProperty`，最后用字段名兜底。
- 必填判定优先取 `@NotNull / @NotBlank / @NotEmpty` 和 primitive 基本类型。
- 类型映射至少支持基础类型、`List / Set`、`Map`、`Enum`、嵌套对象递归展开。

## 完成标准

- 每个接口至少具备 `path`、`method`、`title`、请求参数说明、响应结构。
- 每个接口都归属其 Endpoint 分类。
- `@RequestBody` 接口已生成非空字段级请求 schema。
- 响应对象已生成非空字段级 schema。
- 重复执行不会产生重复接口。
- 用户明确要求“仅预览”时，才允许只输出将上传的数据摘要。

## 失败处理

- MCP 连接失败：立即停止并返回检查项。
- 分类不存在且无权限创建：停止并提示改用可写分类。
- DTO / VO / PO 类型无法解析时：该接口标记失败，记录具体类型与位置。
- 单接口解析或上传失败：记录后继续，最终汇总失败清单。

## 输出要求

- 扫描范围：模块 + Endpoint 路径。
- 接口统计：扫描数、解析数、成功数、失败数。
- YApi 目标：项目、分类。
- Endpoint 分组映射：`Endpoint -> 分类名 -> catid`。
- 字段覆盖统计：请求字段数、响应字段数、未解析字段数。
- 失败清单与重试建议。
