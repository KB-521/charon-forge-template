# SQL Convention Discovery

有同设计稿或同项目 SQL 时，优先抽取现有约定；只复用目录、命名、排序、幂等和格式，不复制业务数据。

## 抽取步骤

1. 用 `rg` 查当前变更包、同设计稿 `sql/` 目录和历史 SQL 文件。
2. 记录目录、文件名前缀序号、用途后缀、manifest 格式、DDL/DML 写法和回滚方式。
3. 区分强约定和偶然写法：优先同设计稿、同模块、近期仍采用的 SQL。
4. 找不到参考时切换到 `default-generation.md`。
