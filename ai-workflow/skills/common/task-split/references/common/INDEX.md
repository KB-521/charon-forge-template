# 通用拆分规则索引

所有技术方案拆分先读取本索引，再按前端/后端入口读取领域规则。

| 任务事实 | 读取文件 |
| --- | --- |
| 需要确认任务目录、索引职责、设计输入路径 | `task-document-structure.md` |
| 需要生成并行队列、worktree、改动边界 | `parallel-boundary.md` |
| 需要生成或更新可恢复执行摘要 | `resume-summary.md` |
| 需要生成父计划或子任务模板公共块 | `template-blocks.md` |

## 共用原则

- 父计划负责“怎么拆、为什么这样拆、依赖怎么走”。
- 子任务负责“做什么、改哪里、怎么验收、怎么交接”。
- 根索引只登记父需求，父需求索引承接子任务和并行执行细节。
- 子任务数量由复杂度和独立验收出口决定，不使用固定数量下限。
