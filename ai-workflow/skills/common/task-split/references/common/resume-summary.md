# Resume Summary / 执行摘要

## 强制要求

父计划和每个子任务必须包含 `Resume Summary / 执行摘要`。

拆分时先写初始摘要；实现、交接、上下文压缩或并行汇总时持续更新。

## 字段

```markdown
## Resume Summary / 执行摘要
- Goal / 目标：
- Current Status / 当前状态：Draft / Running / Blocked / Done
- Constraints / 关键约束：
- Progress / 当前进展：
- Key Decisions / 关键决策：
- Relevant Files / 相关文件：
- Commands Run / 已运行命令：
- Verified / 已验证：
- Open Questions / 待确认：
- Next Steps / 下一步：
- Blockers / 阻塞点：
- Critical Context / 关键上下文：
```

## 更新口径

- `Progress` 写已完成事实，不写计划。
- `Verified` 写已运行的校验和结果。
- `Blockers` 只写真正阻塞执行的缺口。
- `Critical Context` 写恢复任务必须知道的约束、契约和决策。
