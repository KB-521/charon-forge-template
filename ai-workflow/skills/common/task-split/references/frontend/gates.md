# 前端拆分门禁

## Gate

- Gate 1：父计划未给出页面清单和 PageKey，禁止结束。
- Gate 2：未按页面维度拆分，禁止结束。
- Gate 3：存在一个子任务绑定多个页面或多个主路由，禁止结束。
- Gate 4：存在页面未被任何子任务覆盖，或子任务引用页面清单外页面，禁止结束。
- Gate 5：页面任务缺少业务逻辑、状态策略、权限策略或接口映射，禁止结束。
- Gate 6：子任务缺少验收标准、依赖关系或验证方案，禁止结束。
- Gate 7：根 `tasks/INDEX.md` 或父需求 `INDEX.md` 未更新，禁止结束。
- Gate 8：父计划或父需求 `INDEX.md` 缺少并行执行队列，禁止结束。
- Gate 9：子任务缺少并行执行边界或改动边界，禁止结束。
- Gate 10：父计划或任一子任务缺少 `Resume Summary / 执行摘要`，禁止结束。
- Gate 11：未读取 `../common/INDEX.md` 或缺少通用目录/并行/摘要规则，禁止结束。

## 自检

- [ ] 页面总数等于页面清单中的 PageKey 数。
- [ ] 每个子任务只出现 1 个 PageKey。
- [ ] 已覆盖页面数等于页面总数。
- [ ] 多页面子任务数为 0。
- [ ] 索引中的子任务数等于实际子任务文档数。
