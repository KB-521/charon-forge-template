# 前端依赖与并行

## 默认依赖方向

1. 路由/权限/布局壳 -> 页面任务。
2. API 契约 -> 页面接口映射。
3. 列表页 -> 详情页或操作页的入口依赖。
4. 表单页/流程页 -> 提交成功后的跳转、回写和通知。

## 可并行判断

满足以下条件才标记可并行：

- 页面路由不同，写入范围不重叠。
- 共享组件、类型、API 方法已经明确写入方。
- 一个页面失败不会导致另一个页面主逻辑返工。
- 验证方式可独立执行。

## 前端改动边界

子任务按下列维度写清允许修改和禁止修改：

- 页面容器。
- 业务组件。
- 公共组件。
- store/hook。
- api/mock。
- 共享契约：路由、API、类型、权限码。

并行队列、worktree 和通用边界规则读取 `../common/parallel-boundary.md`。
