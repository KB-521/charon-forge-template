# 历史 Review 问题继承规则

## 加载规则

- 若同名 review 文档已存在，必须联合加载 `PRD + review` 开展审查。
- 禁止只看 PRD 或只看旧 review。
- 旧 review 中的问题、状态与确认结论只作为“历史问题基线”，所有保留问题仍需回到当前 PRD 原文逐条核验。

## 问题匹配

- 同一个问题优先按 `问题标题` 完全一致匹配。
- 若标题有轻微文案调整，则按“同一功能点 + 同一风险”的核心语义匹配。
- 匹配失败时视为新增问题，不得强行继承旧状态。

## 状态复核

- 延续：当前 PRD 原文中问题仍存在。
- 已修复：当前 PRD 原文已补齐或修正。
- 已失效：需求范围变化后该问题不再适用。
- 新增：当前审查首次发现的问题。

## 结论继承

- 若旧 review 的 `确认结论` 已由人工填写，且不为空、不等于 `待人工确认`，新 review 必须保留该结论。
- 若沿用旧问题，必须同步刷新问题描述、影响、建议和状态。
- 已经不成立的问题必须删除、标记已修复/已失效，或改写为当前 PRD 中仍成立的新问题；不得原样继承。
