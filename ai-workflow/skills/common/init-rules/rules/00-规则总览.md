# 00-规则总览

## 适用场景

本目录用于后端 Java / Spring Boot / Maven 项目的初始化、设计、代码生成、实现、评审和 SQL 发布。规则按后端代码生成关注点组织，每个文件是一个大类，文件内部再按子类细分。

## 规则发现流程

1. 先从任务中抽取事实：产物、动作、风险、缺口和不做项。
2. 用任务事实匹配各大类文件的 `## 命中条件`，只下钻命中的大类和子类。
3. 生成前冻结接口、模型、错误码、枚举、事务、DAO、SQL、配置和验证方式。
4. 关键事实未确认时先补设计、标记 BLOCKER 或输出缺口清单，禁止猜测实现。
5. 生成后留下代码证据、测试证据或未测原因、规则自检结论。

## 任务事实

| 维度 | 说明 |
| --- | --- |
| 产物 | API、DTO、VO、PO、Service、DAO、SQL、配置、任务、测试、文档 |
| 动作 | 新增、修改、删除、查询、状态流转、外部调用、导入、导出、发布 |
| 风险 | 权限、租户、幂等、事务、补偿、敏感信息、兼容、性能、回滚 |
| 缺口 | 接口契约、表结构、枚举码值、错误码、SDK、配置、测试环境未确认 |
| 不做项 | 本轮明确不涉及的接口、SQL、外部依赖、测试或发布动作 |

## 通用门禁

| 门禁 | 要求 |
| --- | --- |
| 契约冻结 | 接口、模型、错误码、枚举、事务和 SQL 不明确时，先补设计再生成 |
| 联动生成 | 接口、模型、Service、DAO、SQL、配置、测试和文档按影响范围联动 |
| 敏感信息 | 密钥、令牌、账号、连接串不得进入代码、注释、日志、文档和测试数据 |
| TODO 使用 | TODO 不能替代异常、幂等、安全、测试、事务和发布动作 |
| 交付证据 | 每次交付说明代码证据、测试证据或未测原因、规则自检结论 |
