# 06-DAO与SQL

## 适用场景

生成或修改 DAO、Mapper XML、动态 SQL、分页排序、批量查询、generator 配置、DDL、DML、字典 SQL、索引和发布 SQL 时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | DAO、Repository、Mapper XML、SQL、DDL、DML、索引、字典 SQL、generator 配置 |
| 动作 | 新增表、改字段、增查询、改排序、批量操作、发布 SQL、回滚 SQL |
| 风险 | SQL 注入、N+1、分页排序失控、索引缺失、存量兼容或回滚不明 |
| 可跳过 | 不访问数据库、不修改查询条件、不涉及 SQL 或表结构 |

## 06.1 DAO 与 Mapper

| 对象 | 规则 |
| --- | --- |
| DAO | 基础 CRUD 和简单查询 |
| PlusDAO | 聚合、跨表、跨租户、批量专用查询 |
| Manager | 数据管理和较底层组合能力 |
| Mapper XML | namespace、statement id、resultMap 与 DAO 严格一致 |
| Service | 不直接穿透 Mapper XML 或手写 SQL |

## 06.2 动态 SQL

| 场景 | 规则 |
| --- | --- |
| 条件查询 | 使用参数绑定和条件标签 |
| 模糊查询 | 明确转义和索引影响 |
| 排序 | SortField 或白名单映射，禁止直接透传字段 |
| IN 查询 | 控制列表大小，必要时分批 |
| SQL 拼接 | 禁止字符串拼接 where、order by 和 values |

## 06.3 查询效率

| 场景 | 规则 |
| --- | --- |
| 分页 | SQL 层分页，稳定排序 |
| 过滤 | SQL 层过滤，禁止内存过滤大集合 |
| 排序 | SQL 层排序，字段白名单 |
| 单条查询 | 有唯一条件或限制条件 |
| 批量读取 | 使用批量查询，避免循环查 |
| 批量写入 | 使用批量 insert/update，避免循环逐条写 |
| 大字段 | 按需投影，避免默认 SELECT 大字段 |

## 06.4 generator 同步

| 变更对象 | 必须同步 |
| --- | --- |
| 表字段 | PO、Mapper resultMap、列清单 |
| 查询字段 | Query、Mapper 条件、索引 |
| 排序字段 | SortField、白名单、SQL、索引 |
| 响应字段 | VO、转换器、接口契约 |
| 时间字段 | 创建/更新时间默认值和自动更新口径 |
| 乐观锁 | 版本字段、更新条件、失败处理 |

## 06.5 DDL/DML

| 类型 | 规则 |
| --- | --- |
| 新表 | 包含项目约定基础字段，豁免写明原因 |
| 修改表 | 优先 ALTER TABLE，禁止无说明 DROP + CREATE |
| 字段 | 每列有 COMMENT，类型和默认值明确 |
| 逻辑删除 | 使用统一状态或项目约定口径 |
| DML | 幂等、可重复执行、可回滚 |
| 发布 | 风险评估、执行顺序、回滚方案齐全 |

## 06.6 索引

| 场景 | 规则 |
| --- | --- |
| 高频 WHERE | 评估普通索引或组合索引 |
| WHERE + ORDER BY | 组合索引按左前缀设计 |
| 唯一业务键 | 使用唯一索引兜底 |
| 已有索引 | 新增前检查是否可复用或合并 |
| 写多读少表 | 控制索引数量，避免写入放大 |

## 06.7 字典 SQL

| 场景 | 规则 |
| --- | --- |
| 新增枚举类型 | 生成字典类型和字典项 |
| 枚举新增值 | 追加幂等字典项 |
| 字典禁用 | 使用状态变更，不直接删除 |
| 字段注释 | 标明字典类型或枚举语义 |
| 幂等 | 使用 NOT EXISTS 或项目等价幂等写法 |

## 代码生成检查清单

- DAO 职责是否清晰，Mapper namespace 是否一致。
- 动态 SQL 是否参数化。
- 分页、排序、过滤、租户条件是否下推。
- 是否存在 N+1、循环写库、全量查内存过滤。
- DDL 是否有基础字段、注释、索引和回滚方案。
- DML 和字典 SQL 是否幂等、可重复执行。
- generator、PO、Query、Mapper、VO 是否同步。

## 高风险反例

- 拼接排序字段或 where 条件。
- Service 查全表后内存分页。
- 新增字段只改表不改 PO/Mapper/VO。
- 发布 SQL 无回滚、无幂等、无风险说明。
