# 13-测试质量与交付门禁

## 适用场景

后端代码、SQL、配置、任务、外部调用、open 链路、计费、导入导出生成完成后，执行测试、质量检查、评审和交付说明时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 单测、API mock、验证命令、覆盖率、发布说明、交付说明 |
| 动作 | 生成代码、修改 SQL、调整配置、接入外部能力、发布或回归验证 |
| 风险 | 未测高风险链路、SQL 无回滚、交付缺证据 |
| 可跳过 | 仅分析或只输出方案且明确不落代码、不发布、不执行验证 |

| 子类 | 内容 |
| --- | --- |

| 13.5 SQL 发布门禁 | 风险、顺序、回滚、幂等 |

## 13.1 单元测试

| 对象 | 覆盖要求 |
| --- | --- |
| Service | 成功、失败、权限、状态、事务分支 |
| DAO | SQL 条件、分页、排序、边界 |
| 状态机 | 合法流转、非法流转、并发保护 |
| 工具类 | 正常值、空值、异常值 |
| 补偿逻辑 | 幂等、重试、失败记录 |

## 13.2 API mock

| 对象 | 覆盖要求 |
| --- | --- |
| Controller | 参数校验、响应包装、权限入口 |
| Endpoint | 编排动作、异常映射、审计 |
| DTO | 非空、格式、集合、嵌套校验 |
| VO | 字段裁剪、脱敏、枚举展示 |

## 13.3 覆盖率

| 场景 | 最小要求 |
| --- | --- |
| 普通查询 | 成功 + 空结果/边界 |
| 写接口 | 成功 + 校验失败 + 权限/状态失败 |
| 状态机 | 合法 + 非法 + 并发或重复 |
| open 写 | 成功 + 越权 + 重放/幂等 |
| 导入导出 | 正常文件 + 错误文件 + 边界数据量 |
| 计费 | 成功 + 扣减失败 + 回退失败 |

## 13.4 Java 底线

| 维度 | 要求 |
| --- | --- |
| 可读性 | 方法职责单一，命名表达业务 |
| 控制流 | 避免过深嵌套和不可读分支 |
| 空值 | 入参、查询结果、集合明确处理 |
| 资源释放 | IO、流、连接正确关闭 |
| 集合使用 | 控制大小，避免空指针和并发修改 |
| 安全编码 | 防注入、防敏感信息泄露 |

## 13.5 SQL 发布门禁

| 要素 | 规则 |
| --- | --- |
| 幂等 | 可重复执行 |
| 风险 | 说明影响表、行数、锁表风险 |
| 顺序 | DDL、DML、配置、代码依赖顺序明确 |
| 回滚 | 有可执行回滚或补救方案 |
| 审计 | 高风险 SQL 可追溯 |
| 验证 | 执行后校验语句或检查方式明确 |

## 13.6 最终交付

| 证据 | 内容 |
| --- | --- |
| 代码证据 | 新增/修改文件 |
| 测试证据 | 命令、结果、PASS/FAIL/NOT_RUN |
| 未测原因 | 原因、影响、后续可执行命令 |
| 文档证据 | 设计、API 契约、规则自检 |
| 风险说明 | 剩余风险、兼容影响、发布注意 |

## 代码生成检查清单

- 架构落点、依赖方向、包结构、命名是否正确。
- API 语义、注解、入参校验、统一响应、VO 出参是否正确。
- Service 事务、异常、状态机、锁/幂等、补偿是否闭环。
- DAO/Mapper namespace、动态 SQL、分页排序、批量查询、字段投影、租户条件是否正确。
- DDL/DML 基础字段、默认值、逻辑删除、注释、索引、字典 SQL、配置表归属是否齐全。
- open/openService、外部调用、审计、计费、导入导出、敏感配置和日志脱敏是否满足安全门禁。
- 注释、TODO、测试证据、未测原因、发布/回滚说明是否齐全。

## 高风险反例

- 只生成代码，不补测试或未测原因。
- 高风险链路只测成功用例。
- 真实回归未执行但交付结论写通过。
- SQL 变更没有回滚方案。
