# 12-外部集成文件与计费

## 适用场景

新增或修改第三方 HTTP/SDK/gRPC 调用、外部契约模型、回调、OSS/媒体 URL、翻译、计费、导入和导出功能时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Client、Adapter、外部 DTO、回调模型、媒体 URL、计费处理、导入导出 |
| 动作 | 调用外部服务、接收回调、生成签名 URL、扣费、退款、解析文件、导出文件 |
| 风险 | SDK 未确认、超时重试不明、第三方模型污染内部、计费回退缺失 |
| 可跳过 | 不涉及外部系统、文件、媒体、翻译、计费、导入或导出 |

## 12.1 第三方调用

| 场景 | 规则 |
| --- | --- |
| HTTP/SDK 调用 | 统一经 Adapter、Client、Service 或项目等价边界 |
| Controller/Endpoint | 不直接调用外部系统 |
| 超时 | 每个外部调用明确超时 |
| 重试 | 仅对可重试失败重试 |
| 降级 | 明确降级结果和业务影响 |
| 日志 | 记录接口名、业务主键、请求标识 |

## 12.2 外部契约模型

| 对象 | 规则 |
| --- | --- |
| 请求模型 | 独立建模，贴合外部协议 |
| 响应模型 | 独立建模，不直接返回前端 |
| 回调模型 | 校验签名、状态、幂等 |
| 字段转换 | 集中在适配层 |
| 异常映射 | 转为可理解业务失败 |

## 12.3 媒体 URL

| 对象 | 规则 |
| --- | --- |
| OSS 路径 | 存储路径和访问 URL 分离 |
| 桶名 | 不在多处硬编码 |
| 签名 URL | 统一适配过期时间和权限 |
| 公开 URL | 在 VO 或适配层集中转换 |
| 媒体字段 | 不在 Service 多处拼接 |

## 12.4 gRPC/算法

| 要素 | 规则 |
| --- | --- |
| 客户端 | 专门封装，不散落调用 |
| 请求转换 | 内部模型转外部协议 |
| 响应转换 | 外部协议转内部结果 |
| 超时 | 明确超时和重试策略 |
| 错误映射 | 算法错误转业务失败 |
| 上下文 | 透传 requestId 等链路字段 |

## 12.5 翻译

| 场景 | 规则 |
| --- | --- |
| 稳定码值展示 | 使用统一翻译能力 |
| Endpoint 字段拼接 | 禁止逐字段 if/else 拼展示名 |
| Provider | 集中实现 |
| 字段绑定 | 使用统一注解或规则声明 |
| 空值/多值 | 语义一致 |

## 12.6 计费

| 步骤 | 规则 |
| --- | --- |
| 余额查询 | 明确账户和计费维度 |
| 预扣 | 幂等、可追踪 |
| 成功确认 | 和业务成功状态一致 |
| 失败回退 | 本地失败、远程失败都有策略 |
| 注解式计费 | 同时提供 Handler、配置、失败处理和证据 |
| 落点 | 禁止写在 Controller/Endpoint |

## 12.7 导入

| 校验项 | 规则 |
| --- | --- |
| 文件 | 校验空文件、类型、大小 |
| 编码 | 明确编码和解析方式 |
| 表头 | 校验模板版本和必填列 |
| 行数据 | 校验格式、枚举、引用数据 |
| 错误策略 | 明确逐行继续还是整批终止 |
| 结果 | 返回成功数、失败数和失败原因摘要 |

## 12.8 导出

| 要素 | 规则 |
| --- | --- |
| 字段 | 按权限和数据边界裁剪 |
| 数据量 | 大数据量使用异步、限流、分页或分片 |
| 租户 | 遵守租户隔离和 open 安全口径 |
| 格式 | 明确文件类型、编码、表头 |
| 性能 | 避免一次性全量加载 |

## 代码生成检查清单

- 外部调用是否封装到适配边界。
- 外部模型是否和内部模型隔离。
- 超时、重试、异常映射、日志是否完整。
- 媒体 URL 是否集中适配。
- 计费是否有扣减、确认、回退和幂等顺序。
- 导入校验和错误策略是否明确。
- 导出是否控制权限、字段、数据量和性能。

## 高风险反例

- Controller 直接调第三方 SDK。
- 把第三方响应对象直接返回给前端。
- 计费成功后业务失败但没有回退或补偿。
- 导入失败只返回一条笼统错误，无法定位行级问题。
