# 07-上下文租户与open链路

## 适用场景

生成或修改上下文字段、租户隔离、组织隔离、线程上下文、open 接口、open SQL、openService、白名单和公开写接口安全时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 上下文字段、租户字段、组织字段、open 接口、open SQL、openService、白名单 |
| 动作 | 新增入口、透传上下文、跨租户查询、公开访问、异步处理、远程调用 |
| 风险 | 租户越权、上下文泄漏、open 豁免不明、公开写接口缺保护 |
| 可跳过 | 无用户、租户、组织、open、异步或公开链路影响 |

## 07.1 上下文字段

| 字段 | 规则 |
| --- | --- |
| requestId | 全链路追踪，日志必须可定位 |
| tenantId | 租户隔离主字段或项目等价字段 |
| userId | 调用方、操作人、审计人语义明确 |
| orgCode | 组织隔离或组织归属口径明确 |
| source | 外部入口、系统任务、回调等来源明确 |

## 07.2 上下文透传清理

| 场景 | 规则 |
| --- | --- |
| 异步任务 | 显式传入必要上下文 |
| 线程池 | 执行前设置，执行后清理 |
| 定时任务 | 使用系统上下文或任务上下文，不依赖请求残留 |
| 远程调用 | 传递 requestId、tenantId 等必要链路字段 |
| 回调处理 | 重建可信上下文，不能复用旧请求上下文 |

## 07.3 租户隔离

| 场景 | 规则 |
| --- | --- |
| 查询 | 默认带租户或数据域条件 |
| 写入 | 写入前校验租户归属 |
| 批量 | 每个 ID 都需在数据域内 |
| SQL | 租户条件优先下推 DAO/SQL |
| 豁免 | 必须有明确业务依据 |

## 07.4 open 豁免

| 场景 | 判定 |
| --- | --- |
| 登录前访问 | 可评估 open，但必须限制数据范围 |
| 公开展示 | 可评估 open，只返回公开字段 |
| 第三方回调 | 可评估 open，必须校验签名和幂等 |
| 管理端全局读取 | 不等同 open，需按权限模型判定 |
| 系统调度 | 不等同 open，需明确系统上下文 |

## 07.5 open SQL

| 要素 | 规则 |
| --- | --- |
| 数据范围 | 明确可见范围，不能默认全表 |
| 过滤条件 | 写在 SQL 或数据访问层 |
| 越权保护 | 防止通过参数扩大范围 |
| 写接口 | 补审计、防重放、签名或幂等 |
| 测试 | 覆盖可访问和不可访问场景 |

## 07.6 openService

| 判定维度 | 规则 |
| --- | --- |
| 结果给谁看 | 先判断数据可见对象 |
| 由谁修改 | 写操作必须有授权和审计 |
| 默认 Service 过滤 | 默认租户、owner、状态过滤不适用时才评估 |
| 查询形态 | 专用聚合 SQL 或跨域查询才考虑 |
| 证据不足 | 默认使用普通 Service |

## 07.7 白名单

| 动作 | 规则 |
| --- | --- |
| 加入白名单 | 必须说明业务依据和安全边界 |
| DAO 收口 | 白名单 DAO 只能由 open 链路调用 |
| 审计证据 | 记录数据范围、安全策略和测试 |
| 禁止事项 | 配白名单后仍按普通租户链路使用 |

## 代码生成检查清单

- 查询和写入是否默认带租户或数据域条件。
- 上下文字段是否统一命名和来源。
- 异步和外部调用是否透传并清理上下文。
- open 豁免是否有明确业务依据。
- open SQL 是否有权限范围和越权保护。
- open 写接口是否有审计、幂等和防重放设计。
- 白名单能力是否收口到专门 open 链路。

## 高风险反例

- 因为接口叫 open 就跳过租户校验。
- 只在 Controller 层过滤租户，DAO 查询仍然全量。
- 线程池复用 ThreadLocal 导致串租户。
- 配了数据权限白名单但仍按普通 Service 使用。
