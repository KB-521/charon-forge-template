# 03-API接口与响应

## 适用场景

生成或修改 Controller、Endpoint、公开接口、路由、请求参数、响应包装、分页响应、审计或校验注解时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Controller、Endpoint、API、DTO、VO、路由、注解、响应包装、分页对象 |
| 动作 | 新增接口、修改接口、暴露字段、调整请求方法、增加校验或审计注解 |
| 风险 | HTTP 语义错误、接口归属不清、敏感字段透出、响应不兼容 |
| 可跳过 | 不涉及 API、请求/响应字段、路由或公开入口 |

## 03.1 接口归属

| 类型 | 适用场景 | 禁止事项 |
| --- | --- | --- |
| Controller | 标准资源 CRUD | 承载跨资源复杂编排 |
| Endpoint | 跨资源编排、批处理、导入导出、异步触发 | 伪装普通 CRUD |
| 内部 Service | 业务编排和规则收口 | 直接暴露为前端契约 |
| Adapter API | 外部系统适配入口 | 混入内部资源接口 |

## 03.2 HTTP 语义

| 方法 | 语义 | 规则 |
| --- | --- | --- |
| GET | 只读查询 | 禁止写库、触发副作用 |
| POST | 新增、提交、复杂查询或编排 | 查询用 POST 时需有复杂条件或 body 必要性 |
| PUT | 全量更新 | 入参需能表达完整替换语义 |
| PATCH | 局部更新 | 明确可更新字段 |
| DELETE | 删除 | 入参最小化并评估幂等 |

## 03.3 参数来源

| 来源 | 使用场景 | 规则 |
| --- | --- | --- |
| body | 新增、更新、复杂查询、批量动作 | 使用 DTO 并触发结构校验 |
| query | 简单查询、分页、过滤 | 使用 Query 或明确 query 参数 |
| path | 资源 ID、稳定唯一键 | 不放复杂条件 |
| header | 认证、租户、链路标识 | 不承载业务大对象 |

## 03.4 注解规则

| 注解类型 | 使用场景 | 禁止事项 |
| --- | --- | --- |
| 路由注解 | 公开接口入口 | 路径语义和方法语义不一致 |
| 校验注解 | DTO、Query、列表元素、嵌套对象 | 贴在不生效的位置 |
| 审计注解 | 有业务副作用的公开写接口 | 纯查询、DAO、工具类、private 方法滥贴 |
| 权限注解 | 需要鉴权或数据权限的入口 | open 豁免不留依据 |

## 03.5 统一响应

| 响应类型 | 规则 |
| --- | --- |
| 详情 | 返回统一包装的 VO |
| 列表 | 返回统一包装的 List VO 或等价结构 |
| 分页 | 返回统一分页包装 |
| 空结果 | 返回空对象、空集合或统一空分页，不返回 `null` |
| 失败 | 通过统一异常和失败响应出口处理 |

## 03.6 VO 出参

| 字段类型 | 处理方式 |
| --- | --- |
| 内部控制字段 | 默认裁剪 |
| 敏感字段 | 裁剪或脱敏 |
| 存储态字段 | 转换为展示语义 |
| 枚举字段 | 按契约暴露 code/name 或项目统一展示字段 |
| 媒体字段 | 通过统一适配层生成可访问 URL |

## 代码生成检查清单

- 接口归属是资源 CRUD 还是编排动作。
- HTTP 方法是否符合读写语义。
- 入参来源和 DTO/Query 是否一致。
- 写接口是否需要审计、幂等、权限或签名。
- 响应是否统一包装，分页口径是否一致。
- VO 是否隐藏内部字段和敏感字段。

## 高风险反例

- GET 接口执行新增、更新、删除或状态流转。
- Controller 中直接写复杂业务判断。
- 同一动作同时存在 Controller 和 Endpoint。
- 公开接口返回 PO、Map、裸 List 或第三方原始响应。
