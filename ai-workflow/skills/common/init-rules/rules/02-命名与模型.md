# 02-命名与模型

## 适用场景

生成或修改 PO、DTO、VO、BO、Query、Enum、ErrorCode、外部契约模型、方法名、路由名时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | PO、DTO、VO、BO、Query、Enum、ErrorCode、外部请求/响应模型、方法名、路由名 |
| 动作 | 新增模型、修改字段、拆分模型、复用模型、暴露外部契约 |
| 风险 | 模型职责混用、命名歧义、内部模型透出、枚举码值不明 |
| 可跳过 | 不新增或修改任何模型、字段、方法名或路由名 |

## 子类索引

| 子类 | 内容 |
| --- | --- |
| 02.1 模型命名 | PO/DTO/VO/BO/Query/Enum/ErrorCode |
| 02.2 方法命名 | 查询、写入、状态流转、编排动作 |
| 02.3 路由命名 | 资源路径、动作路径、大小写 |
| 02.4 模型边界 | 各类模型职责和禁止复用场景 |
| 02.5 外部契约模型 | 第三方请求、响应、回调模型 |

## 02.1 模型命名

| 类型 | 命名规则 |
| --- | --- |
| PO | 持久化对象，和表或持久化实体主语一致 |
| DTO | 接口入参，按动作区分新增、更新、查询等语义 |
| VO | 接口出参，按前端可见语义命名 |
| BO | 业务中间态，表达内部流程对象 |
| Query | 查询、分页、排序和过滤条件 |
| Enum | 稳定业务离散值 |
| ErrorCode | 业务失败语义和可追踪错误码 |

## 02.2 方法命名

| 动作 | 推荐命名 | 禁止倾向 |
| --- | --- | --- |
| 单条查询 | `getXxx`、`findXxx` | `handleXxx` |
| 列表查询 | `listXxx`、`pageXxx`、`queryXxx` | `dealList` |
| 新增 | `createXxx`、`addXxx` | `saveXxx` 语义不明时慎用 |
| 更新 | `updateXxx`、`modifyXxx` | `processXxx` |
| 删除 | `deleteXxx`、`removeXxx` | `doDelete` |
| 状态流转 | `submitXxx`、`confirmXxx`、`cancelXxx` | `changeStatus` 无业务动作 |
| 编排动作 | 使用真实业务动词 | `do`、`process`、`handle`、`deal` |

## 02.3 路由命名

| 场景 | 规则 |
| --- | --- |
| 资源路径 | 小写、稳定、围绕业务主语 |
| 详情 | 使用资源 ID 或稳定唯一键 |
| 分页/查询 | 查询条件进入 Query，不靠路由拼临时条件 |
| 编排动作 | 动作名表达业务语义，不伪装 CRUD |
| 大小写 | 禁止驼峰、拼音混用、临时缩写 |

## 02.4 模型边界

| 模型 | 只能承载 | 禁止承载 |
| --- | --- | --- |
| PO | 持久化字段 | 接口校验、展示字段、第三方字段 |
| DTO | 入参字段和结构校验 | 出参字段、持久化控制字段 |
| VO | 前端可见字段 | 内部控制字段、敏感字段、存储态字段 |
| BO | 内部业务中间态 | 直接作为接口契约 |
| Query | 查询、分页、排序、过滤 | 写入字段、业务流程状态 |

## 02.5 外部契约模型

| 对象 | 规则 |
| --- | --- |
| 外部请求 | 独立建模，字段名贴合外部协议 |
| 外部响应 | 独立建模，不直接透出到内部接口 |
| 回调模型 | 独立建模并校验签名、状态和幂等 |
| 字段转换 | 集中在 adapter/client/service 边界 |

## 代码生成检查清单

- 模型后缀是否表达真实职责。
- 方法名是否能直接看出业务动作。
- Query 是否只表达查询语义。
- VO 是否裁剪内部字段和敏感字段。
- 外部契约模型是否独立建模。
- 枚举、错误码、状态值是否有统一归属。

## 高风险反例

- 一个 DTO 同时作为新增、更新、查询和出参。
- 直接把 PO 返回给前端。
- 为第三方接口复用内部领域对象。
- 新增排序字段但不改 SQL 和索引。
