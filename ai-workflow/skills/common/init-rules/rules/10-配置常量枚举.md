# 10-配置常量枚举

## 适用场景

新增或修改配置文件、环境差异、敏感配置、业务常量、锁常量、幂等前缀、枚举、契约枚举和配置表时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 配置文件、配置类、常量、枚举、配置表、锁 key、幂等 key |
| 动作 | 新增配置、修改默认值、增加码值、调整开关、抽取常量 |
| 风险 | 敏感配置泄露、魔法值散落、枚举不同步、环境差异不明 |
| 可跳过 | 不新增或修改配置、常量、枚举、码值、开关或配置表 |

| 子类 | 内容 |
| --- | --- |
| 10.1 配置文件 | 默认配置、环境差异、配置说明 |
| 10.2 敏感配置 | 密码、token、密钥、连接串 |
| 10.3 业务常量 | 魔法值、配置键、专题前缀 |
| 10.4 锁常量 | 锁 key、幂等 key、业务前缀 |

| 10.7 配置表 | 运营可调、租户独立、开关策略 |

## 10.1 配置文件

| 类型 | 规则 |
| --- | --- |
| 默认配置 | 放通用默认值 |
| 环境配置 | 放环境差异，不复制无差异配置 |
| 新增配置 | 说明默认值、所属模块、用途 |
| 配置校验 | 必要配置启动期校验 |
| 配置删除 | 确认无引用和兼容影响 |

## 10.2 敏感配置

| 类型 | 处理方式 |
| --- | --- |
| 账号密码 | 外置到密钥系统、环境变量或安全配置中心 |
| token | 不写入代码、日志、注释、文档 |
| AK/SK | 外置并限制权限范围 |
| 连接串 | 不复制到文档和测试样例 |
| 签名密钥 | 启动期校验缺失和格式 |

## 10.3 业务常量

| 对象 | 规则 |
| --- | --- |
| 稳定字符串 | 放 Constants 或项目等价位置 |
| 数值常量 | 写清单位和业务含义 |
| 配置键 | 集中维护，禁止散落硬编码 |
| 专题前缀 | 统一归属，避免重复造前缀 |
| 魔法值 | 禁止在 Endpoint、Controller、Manager、ServiceImpl 散落 |

## 10.4 锁常量

| 对象 | 规则 |
| --- | --- |
| 锁 key | 稳定业务前缀 + 业务唯一键 |
| 幂等 key | 动作 + 业务唯一键 + 必要上下文 |
| 常量位置 | 统一放 LockConstants 或项目等价位置 |
| 注释 | 说明作用范围和组成部分 |

## 10.5 业务枚举

| 规则 | 说明 |
| --- | --- |
| 集中定义 | 同一业务语义只保留一个枚举 |
| 优先复用 | 新增前查已有枚举 |
| 同步状态机 | 枚举变化同步状态流转 |
| 同步字典 | 需要展示时同步字典 SQL |
| 同步测试 | 新值覆盖成功和失败场景 |

## 10.6 契约枚举

| 场景 | 规则 |
| --- | --- |
| 对外接口 | 不直接暴露内部枚举细节 |
| 第三方协议 | 独立建模并集中转换 |
| open 链路 | 枚举语义保持稳定 |
| 派生值 | 放 VO 或契约适配层 |

## 10.7 配置表

| 适合配置表 | 不适合配置表 |
| --- | --- |
| 需不发版调整 | 永久稳定常量 |
| 管理端编辑 | 代码结构分支 |
| 按 tenant 独立 | 只读协议枚举 |
| 运营可调限额、概率、时间窗、开关 | 低频且需编译约束的常量 |

## 代码生成检查清单

- 新配置是否有默认值、环境差异和用途说明。
- 敏感配置是否外置且启动期校验。
- 业务常量、锁 key、幂等 key 是否集中归属。
- 是否存在魔法值散落。
- 枚举是否复用已有语义。
- 枚举变更是否同步契约、字典、错误码、状态机和测试。

## 高风险反例

- 把 token、密码、连接串写入代码或文档。
- 为每个方法临时定义同义常量。
- 运营可调参数写死在代码里。
- 内部枚举直接作为外部协议返回。
