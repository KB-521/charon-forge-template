# 11-异步任务锁与幂等

## 适用场景

新增或修改定时任务、异步任务、线程池、并发写、重复触发、外部回调、重试、补偿、分布式锁和幂等逻辑时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 定时任务、异步任务、线程池、锁、幂等键、重试、补偿记录 |
| 动作 | 并发写、重复提交、外部回调、异步执行、失败重试、补偿执行 |
| 风险 | 重复扣减、重复写入、锁 key 不稳、无界线程池、补偿不可重放 |
| 可跳过 | 同步只读链路且无并发、副作用、重试、锁或幂等需求 |

## 11.1 定时任务

| 要素 | 规则 |
| --- | --- |
| 触发器 | 只负责触发，不堆复杂业务 |
| 执行组件 | 重业务下沉 Service 或任务执行器 |
| 任务范围 | 明确处理数据范围和分页策略 |
| 任务结果 | 记录处理数量、成功数、失败数 |
| 重入 | 评估锁、幂等和重复执行 |

## 11.2 线程池

| 要素 | 规则 |
| --- | --- |
| 线程名 | 可定位业务域和任务类型 |
| 核心线程数 | 根据负载和资源评估 |
| 队列 | 容量受控，禁止无界队列 |
| 拒绝策略 | 明确失败、降级或回退处理 |
| 监控 | 关键线程池要可观测 |
| 默认线程池 | 禁止承载复杂核心业务 |

## 11.3 锁

| 场景 | 规则 |
| --- | --- |
| 并发写 | 必须评估锁或条件更新 |
| 定时重跑 | 任务维度加锁 |
| 外部回调 | 按业务唯一键加锁或幂等 |
| 锁范围 | 只包真实临界区 |
| 锁 key | 稳定、可定位、集中常量 |
| 超时 | 有过期时间和释放策略 |

## 11.4 幂等

| 场景 | 幂等键组成 |
| --- | --- |
| 重复提交 | 用户/租户 + 业务唯一键 + 动作 |
| 支付/计费 | 订单号或流水号 + 动作 |
| 外部回调 | 外部事件 ID + 业务主键 |
| 消息消费 | 消息 ID + 业务动作 |
| 定时补偿 | 业务主键 + 补偿动作 |

## 11.5 重试

| 要素 | 规则 |
| --- | --- |
| 次数 | 有最大次数 |
| 间隔 | 避免固定短间隔打爆下游 |
| 停用 | 有开关或终止条件 |
| 记录 | 记录每次失败原因 |
| 告警 | 超限或持续失败要可见 |

## 11.6 补偿

| 要素 | 规则 |
| --- | --- |
| 补偿记录 | 业务主键、动作、状态、失败原因 |
| 可重复执行 | 补偿动作必须幂等 |
| 顺序 | 明确补偿前置条件 |
| 人工兜底 | 高风险链路保留人工处理方式 |
| 可观测 | 日志、状态、指标或任务表可追踪 |

## 11.7 上下文

| 场景 | 规则 |
| --- | --- |
| 异步提交 | 显式携带必要上下文 |
| 线程执行 | 执行前设置，finally 清理 |
| 定时任务 | 使用系统上下文或任务上下文 |
| 远程调用 | 传递 requestId 等链路字段 |

## 代码生成检查清单

- 定时任务是否只触发不堆业务。
- 线程池是否专用、命名、容量可控。
- 并发场景是否有锁或幂等策略。
- 锁范围是否足够小。
- 幂等键是否稳定且能区分动作。
- 重试和补偿是否有限次、可观测、可停用。
- 上下文是否透传和清理。

## 高风险反例

- 使用默认线程池跑核心业务。
- 锁包住远程调用和整条长事务。
- 幂等键使用随机 UUID，无法识别重复业务请求。
- 无限重试导致雪崩或重复副作用。
