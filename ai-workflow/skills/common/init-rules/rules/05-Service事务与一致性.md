# 05-Service事务与一致性

## 适用场景

生成或修改 Service、ServiceImpl、ServicePlus、Manager 编排、事务边界、跨系统协同、回滚和补偿逻辑时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | Service、ServiceImpl、ServicePlus、Manager、事务注解、补偿逻辑、编排方法 |
| 动作 | 新增业务流程、修改写链路、跨系统协同、状态更新、失败回滚 |
| 风险 | 事务边界不明、远程调用包事务、补偿缺失、Service 职责过重 |
| 可跳过 | 只改纯查询且不涉及事务、副作用、外部调用或状态变化 |

| 子类 | 内容 |
| --- | --- |
| 05.1 Service 职责 | 业务编排、规则收口、事务评估 |
| 05.2 ServicePlus 职责 | 通用复用、能力封装 |

## 05.1 Service 职责

| 职责 | 规则 |
| --- | --- |
| 业务编排 | 主业务流程收口在 Service |
| 规则收口 | 存在性、权限、状态、幂等在 Service 主链路完成 |
| 事务评估 | 每条写链路先评估事务策略 |
| 外部协同 | 协调外部调用、消息、补偿 |

## 05.2 ServicePlus 职责

| 可以承载 | 不应承载 |
| --- | --- |
| 通用查询能力 | 单个业务流程强规则 |
| 通用写入能力 | 接口专属参数拼装 |
| 复用校验能力 | 前端契约逻辑 |
| 横向公共能力 | 临时特殊分支 |

## 05.3 事务边界

| 策略 | 使用场景 |
| --- | --- |
| 整体本地事务 | 单库或同事务资源的强一致写链路 |
| 分段事务 | 外部调用、消息、副作用和本地写混合链路 |
| 无事务补偿 | 无法用本地事务覆盖的跨系统链路 |
| 条件更新 | 状态机、并发写、幂等写 |

## 05.4 远程调用与事务

| 顺序 | 风险 | 规则 |
| --- | --- | --- |
| 先远程后本地 | 本地失败导致远程副作用悬挂 | 必须有回退或补偿 |
| 先本地后远程 | 远程失败导致本地状态需回滚或补偿 | 必须有失败状态和重试 |
| 事务内远程 | 长事务、锁等待、不可控耗时 | 默认避免，确需使用要说明原因 |
| 异步远程 | 最终一致性 | 必须可追踪、可重试 |

## 05.5 回滚补偿

| 要素 | 规则 |
| --- | --- |
| 补偿动作 | 幂等，可重复执行 |
| 失败记录 | 记录业务主键、失败原因、重试状态 |
| 重试 | 有次数上限和停用开关 |
| 人工兜底 | 高风险链路保留人工处理入口或证据 |
| 可观测 | 日志、状态、告警或任务记录可追踪 |

## 代码生成检查清单

- 主业务流程是否收口在 Service。
- 事务范围是否覆盖必要写操作且不过度包裹远程调用。
- 远程调用与本地事务的先后顺序是否明确。
- 失败后是否能回滚或补偿。
- 补偿是否幂等、可重试、可观测。
- ServicePlus 是否只放通用复用逻辑。

## 高风险反例

- Controller 直接操作 DAO 或拼业务流程。
- 一个事务包住长时间外部调用。
- 远程调用成功后本地写库失败但没有补偿。
- 补偿逻辑重复执行会产生二次副作用。
