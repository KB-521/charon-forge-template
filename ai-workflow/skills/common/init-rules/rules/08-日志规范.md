# 08-日志规范

## 适用场景

新增或修改接口入口、Service 主链路、关键分支、状态变化、外部调用、异常处理、定时任务、异步任务和审计日志时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | 日志、审计注解、异常处理、状态变化记录、任务结果记录 |
| 动作 | 新增入口、修改主链路、增加分支、外部调用、状态变化、异常捕获 |
| 风险 | 敏感信息泄露、无失败上下文、重复打日志、缺少审计证据 |
| 可跳过 | 纯模型、纯 SQL 或测试改动且不影响运行链路日志 |

## 子类索引

| 子类 | 内容 |
| --- | --- |
| 08.1 基础日志打印 | 入口、分支、状态变化、外部调用 |
| 08.2 日志级别 | debug、info、warn、error |
| 08.3 异常日志 | 抛异常前、catch 单点、异常栈 |
| 08.4 敏感信息与脱敏 | 密码、token、手机号、证件号、请求体 |
| 08.5 审计日志注解 | 写接口审计、参数记录策略、禁用场景 |

## 08.1 基础日志打印

| 落点 | 级别 | 内容 |
| --- | --- | --- |
| 接口入口 | debug | 请求摘要、requestId、关键业务入参 |
| Service 入口 | debug | 业务主键、用户、租户、动作 |
| 关键分支 | info | 分支原因、业务主键、处理结果 |
| 状态变化 | info | 业务主键、变更前状态、变更后状态、触发动作 |
| 外部调用 | info/debug | 外部接口名、业务主键、请求标识 |
| 定时任务 | info | 任务名、处理数量、成功失败摘要 |

## 08.2 日志级别

| 级别 | 使用场景 | 禁止事项 |
| --- | --- | --- |
| debug | 入参摘要、查询条件、调试信息 | 打完整请求体、敏感字段 |
| info | 状态变化、锁命中、任务结果、外部副作用触发 | 高频循环刷屏 |
| warn | 可恢复异常、降级、非预期但不影响主流程 | 用 warn 掩盖真实失败 |
| error | 失败上下文、异常栈、外部调用失败 | 多点重复打印、无异常栈 |

## 08.3 异常日志

| 场景 | 规则 |
| --- | --- |
| 抛业务异常前 | 仅当 catch 处会丢失上下文时补 error |
| catch 中 | 只保留一条 `log.error(...)` |
| error 内容 | requestId、业务主键、关键上下文、`e.getMessage()`、`e` |
| 全局异常处理 | 避免和 Service catch 重复打印 |
| 外部调用失败 | 打接口名、业务主键、请求标识和异常栈 |

## 08.4 敏感信息与脱敏

| 信息类型 | 处理方式 |
| --- | --- |
| 密码 | 不打印 |
| token、密钥、AK/SK | 不打印或只打印不可还原摘要 |
| 手机号 | 脱敏后打印 |
| 证件号、银行卡 | 默认不打印 |
| 完整请求体 | 不打印，只打字段清单或摘要 |
| 第三方响应 | 白名单字段打印，禁止完整透出 |
| 文件内容 | 不打印内容，只打文件名、大小、类型、摘要 |

## 08.5 审计日志注解

| 场景 | 规则 |
| --- | --- |
| 新增、更新、删除 | 有业务副作用的公开写接口必须评估 |
| 批量写、导入导出 | 必须评估审计日志 |
| 状态流转 | 必须记录业务动作和主键 |
| 奖励、计费、资产变化 | 必须评估审计和敏感字段 |
| 纯查询接口 | 默认不贴 |
| DAO、工具类、private 方法 | 不贴 |
| 参数记录策略 | 只放可定位业务问题的非敏感字段 |
| 敏感字段 | 禁止放密码、token、证件号、手机号全量、完整请求体 |

## 代码生成检查清单

- 入口是否有可定位请求的摘要日志。
- 状态变化、锁冲突、外部副作用是否有 info 日志。
- catch 是否只有一条 error 且带异常栈。
- 日志是否包含 requestId 或等价链路标识。
- 日志中是否存在敏感字段或完整大对象。
- 写接口是否评估审计日志注解。
- 参数记录策略是否只包含非敏感定位字段。

## 高风险反例

- catch 中连续打印 warn、error、error。
- 直接打印完整 DTO、第三方响应或文件内容。
- 日志里出现 token、密码、手机号全量。
- 纯查询接口滥贴审计日志注解。
