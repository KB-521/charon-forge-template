# 09-注释文档与TODO

## 适用场景

新增或修改对外 API、核心 Service、复杂 private 方法、关键字段、主业务链路、TODO/FIXME、交付文档和规则自检时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | API 注释、类注释、方法注释、字段注释、TODO/FIXME、交付说明 |
| 动作 | 新增公开入口、复杂流程、关键字段、副作用方法、遗留待办 |
| 风险 | 业务口径不清、TODO 替代实现、敏感字段无说明、交付证据缺失 |
| 可跳过 | 简单内部重命名或机械格式调整且无业务语义变化 |

## 子类索引

| 子类 | 内容 |
| --- | --- |
| 09.1 接口与类注释 | API 类、Service 类、核心组件 |
| 09.2 方法注释 | 对外方法、复杂 private 方法、副作用方法 |
| 09.3 字段注释 | 状态、类型、金额、时间、次数、敏感字段 |
| 09.4 主业务链路注释 | 事务、状态、异步、补偿、远程调用 |
| 09.5 TODO/FIXME | 动作、触发条件、收敛方向 |
| 09.6 交付文档证据 | 代码证据、测试证据、规则自检 |

## 09.1 接口与类注释

| 对象 | 何时需要 | 内容 |
| --- | --- | --- |
| API 类 | 公开入口 | 资源或业务域、主要职责 |
| Endpoint 类 | 编排入口 | 编排场景、边界、副作用 |
| Service 类 | 核心业务 | 业务职责和主要规则 |
| Adapter/Client 类 | 外部集成 | 外部系统、协议、失败处理边界 |
| 定时任务类 | 调度任务 | 触发条件、处理范围、幂等策略 |

## 09.2 方法注释

| 方法类型 | 注释内容 |
| --- | --- |
| 对外方法 | 用途、关键入参、出参、失败语义 |
| 核心 Service 方法 | 业务规则、事务、副作用 |
| 复杂 private 方法 | 为什么拆出、输入输出、边界条件 |
| 远程调用方法 | 外部接口、超时、异常映射 |
| 补偿方法 | 补偿对象、幂等条件、失败处理 |

## 09.3 字段注释

| 字段类型 | 注释要求 |
| --- | --- |
| 状态 | 枚举语义或状态机含义 |
| 类型 | 类型范围、字典或枚举来源 |
| 金额 | 单位、币种、精度 |
| 时间 | 时区、单位、业务含义 |
| 次数/额度 | 统计口径、重置周期 |
| 锁 key/幂等 key | 组成部分和作用范围 |
| 敏感字段 | 用途和脱敏要求 |
| 上下游字段 | 来源、去向、兼容影响 |

## 09.4 主业务链路注释

| 链路类型 | 注释重点 |
| --- | --- |
| 事务链路 | 事务范围和失败回滚原因 |
| 状态流转 | 前置状态、触发动作、失败拦截 |
| 异步任务 | 触发、上下文、幂等、补偿 |
| 远程调用 | 为什么先调用或后调用、失败策略 |
| 聚合查询 | 数据范围、过滤口径、性能边界 |
| 计费/资产 | 扣减、确认、回退、幂等 |

## 09.5 TODO/FIXME

| 规则 | 正例方向 | 反例 |
| --- | --- | --- |
| 必须带动作 | 补齐某配置、替换某临时策略 | `TODO` |
| 必须带收敛方向 | 等某契约确定后删除兼容分支 | `以后优化` |
| 不能跳过必做项 | 不得跳过测试、幂等、安全、异常 | `TODO: 后面补测试` |
| 风险显式 | 影响正确性时说明风险 | 无风险说明 |

## 09.6 交付文档证据

| 证据 | 内容 |
| --- | --- |
| 代码证据 | 新增和修改文件清单 |
| 测试证据 | 成功、失败、边界用例和执行结果 |
| 未测原因 | 未执行原因、风险和可执行命令 |
| 规则自检 | 命中规则和自检结论 |
| 发布说明 | SQL、配置、回滚和风险说明 |

## 代码生成检查清单

- 核心类、核心方法和关键字段是否有必要注释。
- 主链路注释是否说明业务口径和风险，而不是重复代码。
- TODO 是否可追踪、可收敛。
- 是否存在用 TODO 代替必做动作。
- 交付说明是否包含代码、测试和规则自检。

## 高风险反例

- 每行代码都写语法翻译式注释。
- 状态字段没有说明枚举语义。
- `TODO: 后续处理` 这类无法追踪的欠账。
- 用 TODO 跳过测试、幂等或异常处理。
