# 04-校验错误与状态

## 适用场景

生成或修改 DTO 校验、业务前置校验、权限校验、删除接口、错误码、异常处理、状态机和状态流转时读取本规则。

## 命中条件

| 维度 | 命中信号 |
| --- | --- |
| 产物 | DTO 校验、业务校验、权限校验、错误码、异常、状态字段、删除接口 |
| 动作 | 新增校验、修改状态、删除资源、增加错误语义、处理异常分支 |
| 风险 | 状态流转不闭环、错误码归属不明、权限或租户绕过、删除不幂等 |
| 可跳过 | 纯展示、纯查询且不新增校验、状态、错误或权限语义 |

## 04.1 DTO 结构校验

| 校验类型 | 规则 |
| --- | --- |
| 非空 | 必填字段在 DTO 边界声明 |
| 长度 | 字符串、列表、文件名等设置上限 |
| 格式 | 手机号、邮箱、URL、日期、编码等按业务格式校验 |
| 集合 | 校验集合大小和元素合法性 |
| 嵌套对象 | 嵌套 DTO 必须触发级联校验 |

## 04.2 业务前置校验

| 校验对象 | 规则 |
| --- | --- |
| 存在性 | 引用数据前先确认存在 |
| 状态 | 写入和流转前校验当前状态 |
| 权限 | 校验调用方是否可读、可改、可删除 |
| 租户 | 默认校验租户或数据域归属 |
| 组织 | 涉及组织隔离时校验 orgCode 或等价字段 |
| 外部依赖 | 远程主数据校验失败时必须拦截 |

## 04.3 删除入参

| 场景 | 入参规则 |
| --- | --- |
| 单条删除 | 主键、版本、幂等键或必要上下文 |
| 批量删除 | ID 列表上限、失败策略、幂等语义 |
| 逻辑删除 | 明确状态值和查询过滤口径 |
| 物理删除 | 必须有业务依据、风险说明和回滚策略 |

## 04.4 错误码

| 规则 | 说明 |
| --- | --- |
| 唯一 | 同一失败语义只保留一个错误码 |
| 可复用 | 新增前先查已有语义 |
| 可追踪 | 错误码能定位业务域和失败原因 |
| 集中归属 | 放在错误码枚举或契约常量中 |
| 同步契约 | 新增错误码同步接口文档和测试 |

## 04.5 异常处理

| 异常类型 | 处理方式 |
| --- | --- |
| 业务失败 | 抛业务异常并携带标准错误码 |
| 参数错误 | 结构校验或业务校验失败 |
| 基础设施异常 | 在边界映射为业务失败 |
| 第三方异常 | 转为可理解的业务失败，不透出原始异常 |
| 未知异常 | 统一捕获、记录、返回标准失败 |

## 04.6 状态机

| 要素 | 规则 |
| --- | --- |
| 前置状态 | 写库前校验允许状态 |
| 触发动作 | 使用业务动作表达流转原因 |
| 失败码 | 非法流转有明确错误码 |
| 并发 | 状态更新要评估版本、锁或条件更新 |
| 补偿 | 重试和补偿场景必须幂等 |

## 代码生成检查清单

- DTO 结构校验是否覆盖必填、长度、格式和集合边界。
- 写入前是否完成存在性、状态、权限和租户校验。
- 删除接口是否只接收必要字段。
- 错误码是否复用或新增到统一位置。
- catch 是否映射为业务失败而不是吞掉。
- 状态流转是否有前置状态、失败码和并发保护。

## 高风险反例

- 前端传什么就直接写库。
- 删除接口接收完整 DTO 或 PO。
- catch 后返回成功。
- 状态更新只按 ID 改，不校验当前状态。
