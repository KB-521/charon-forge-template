# 前端方案门禁清单

## 1. 输入冻结
- [ ] 已引用 PRD、原型、审查报告版本
- [ ] 页面清单与用户流程已完整提取
- [ ] 待确认项有 owner 与截止时间
- [ ] 核心不确定项已确认（未确认项仅可保留为阻塞）

## 2. 信息架构
- [ ] 页面/路由/导航关系完整
- [ ] 路由鉴权与重定向规则明确
- [ ] 多角色入口与访问边界明确
- [ ] 已按页面维度拆分（每页有独立目标与边界）
- [ ] 每个页面都有业务逻辑清单（触发、校验、结果、失败处理）

## 3. 组件架构
- [ ] 页面层、业务组件层、基础组件层边界清晰
- [ ] 关键组件输入输出明确
- [ ] 复用优先，不重复造轮子
- [ ] 已输出公共组件清单，且明确复用页面

## 4. 状态与交互
- [ ] 服务端状态与客户端状态职责分离
- [ ] 至少 3 条核心状态机完整
- [ ] 每个页面定义 loading/empty/error/no-permission
- [ ] 异常回退路径清晰

## 5. 进入评审判定
- [ ] 无未处理 BLOCKER
- [ ] 路由、权限、状态机已冻结
- [ ] 每个功能点可映射到页面 + 状态 + 责任角色
- [ ] 每个功能点可映射到页面 + 业务逻辑 + API + 公共组件
- [ ] 产物为单文档交付（未拆分为多份设计文档）
